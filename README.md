# Project Title (Music Player Manager)

A combination Supabase database and python code that interact with each other, allowing the user to influence the database from the python code

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install up to version 3.13 of Python
2. Pip install supabase
3. Export the unique url and key from the supabase database you’re working from in an .env file

Instructions for using the software:

1. Open terminal
2. If running only select query, run by writing py MusicPlayerManager.py in the terminal
3. If running add or remove query, ensure that the function for the query is run above the select query in the file
4. If only running update query, ensure that is the only query running.
